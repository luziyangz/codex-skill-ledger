# Skilune｜技序

Skilune · 技序的产品标识、颜色与界面应用规范。

## 名称

- **英文品牌：Skilune**，读作「斯基卢恩」，建议英文产品名独立使用。
- **中文名称：技序**。“技”对应 AI 技能，“序”表达清晰归属、可靠记录和有序管理。
- **品牌主张：让每个技能，各就其位。**
- **产品描述：本地 AI 技能管理空间。** 当前专注 Codex，按全局与项目组织安装、使用方法和变更记录。

Skilune 是由 Skill 与 Lune 组合的命名提案。Lune 的意象用于强调围绕用户与项目组织能力；不表示产品具备技能编排或执行引擎功能。

## 视觉

Logo 采用模块化的 S 形符号：三道水平结构表达全局、项目与技能的分层，首尾相连表达安装和移除的生命周期；负空间在小尺寸下仍可辨认。

| 项目 | 方案 |
| --- | --- |
| 主色 | 深松绿 `#112E2B` |
| 强调色 | 薄荷绿 `#65E6BD` |
| 辅助色 | 苔绿 `#245B50` |
| 背景色 | 暖雾白 `#F5F7F2` |
| 字体 | Segoe UI / Microsoft YaHei，保持本地界面无额外字体依赖 |

## 文件

- `icon.svg`：应用图标，可缩放，带底色。
- `mark.svg`：透明背景单色图形。
- `wordmark.svg`：英文与中文组合标识。
- `logo.png`：透明背景 PNG 图标导出。
- `app.ico`：Windows 桌面和开始菜单图标。
- `brand-board.png`：品牌方案总览。
- `preview.html`：本地品牌预览页。
- `product-preview.html` / `product-preview.png`：使用示例数据的真实界面预览。

本地页面、图标、入口名称、预览图与说明统一使用 Skilune · 技序。界面移除品牌预览标签、装饰性窗口栏、底部设计解说和发布状态；设计依据保存在本文档中。接口、数据路径和历史记录保持兼容。

命名做了基础公开检索，不据此声明商标、域名或法律权利可用。
